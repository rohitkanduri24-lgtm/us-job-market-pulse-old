    About this project

    Data comes from the U.S. Bureau of Labor Statistics (JOLTS, Current Population Survey, Current Employment Statistics), the BLS Public Data API (national, industry and state detail), NBER recession dates and, when configured, weekly unemployment insurance claims from the Department of Labor via the FRED API. A GitHub Actions workflow re-runs the Python pipeline every week and republishes this page.

    Health Score method: for each indicator (openings per unemployed, hires rate, quits rate, layoffs rate, unemployment rate and, when available, initial claims) we compute where the month ranks against every month since 2001, flip the direction for "lower is better" measures, and average the percentiles. 70+ = Hot, 55-70 = Healthy, 40-55 = Cooling, below 40 = Weak. It is a descriptive index, not a forecast.

    JOLTS data lags about five weeks; claims data is weekly; state estimates are modeled by BLS and are revised.
